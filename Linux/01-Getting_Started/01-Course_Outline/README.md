---

## 🎯 What This Lesson Covers

An overview of the entire DevOp Camp ZTM Linux course — what topics are covered, the order of study, and what you'll be able to do by the end.

---

## 📝 Key Takeaways

- **Course focus:** Practical, hands-on Linux for DevOps and system administration
- **Approach:** Learn by doing — every concept is followed by challenges and real exercises
- **Scope:** From the very basics (terminal, filesystem) all the way to Bash scripting and production projects (Docker, Ansible, web/DNS servers)

---

## 🗺️ Course Path Summary

| Phase                | Modules | Topics                                       |
| :------------------- | :------ | :------------------------------------------- |
| **Foundations**      | 1–6     | Terminal, File System                        |
| **Users & Security** | 7–10    | Users, Groups, Permissions                   |
| **System Internals** | 11–18   | Processes, Networking, Software, Sysadmin    |
| **Scripting**        | 19–20   | Bash Shell Scripting                         |
| **Projects**         | 21–28   | Docker, Security Hardening, Web/DNS, Ansible |
