# ⚡ Module 06 — Challenges: The Linux File System

## Overview
Hands-on challenges testing everything from Module 05 — The Linux File System. These challenges cover navigating paths, working with `ls`, file timestamps, file types, viewing files, copy/move/delete operations, `find`, `locate`, archiving with `tar`, and creating hard/symlinks.

| Challenge Set | Topics Covered | Status |
| :--- | :--- | :---: |
| **[Set A — Paths, ls, Timestamps, Types, Viewing](./challenges/README.md#set-a)** | pwd, cd, ls flags, stat, file types, cat/less/tail | ⬜ |
| **[Set B — cp, mv, rm, shred](./challenges/README.md#set-b)** | Copying, moving, renaming, safe deletion | ⬜ |
| **[Set C — locate, find](./challenges/README.md#set-c)** | locate, updatedb, find with options, find+exec | ⬜ |
