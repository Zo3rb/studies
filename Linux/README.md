# 🐧 Linux Mastery — DevOp Camp ZTM

Welcome to the **Linux Mastery** study repository! This project follows the **DevOp Camp ZTM** video course, building professional-grade Linux skills for real-world DevOps and engineering work.

## 🎯 Goal

Master Linux fundamentals through Module 19 (Bash Shell Scripting) — documented, practiced, and challenged — as a foundation for Coursera specializations and job-level proficiency.

## 📅 Study Period

**Oct 30 – Nov 15, 2026** | 2–3 hours/day | All days

## 🛠️ Project Structure

Each module folder contains:

- `README.md` — Module overview and objectives
- `<lesson-name>/README.md` — Distilled lesson notes, key commands, flags, and gotchas
- `<lesson-name>/practice.sh` — Annotated, runnable bash practice script
- `challenges/README.md` — Challenge objectives and your solution approach
- `challenges/challenge.sh` — Script solving the challenge tasks
- `quiz.md` — Quiz questions and your answers (self-assessment log)
