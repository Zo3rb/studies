## 🎯 What This Lesson Covers
Why engineers and developers migrate to Linux, the practical benefits, and what to expect during the transition.

---

## 📝 Key Concepts

### Why Linux?

| Reason | Detail |
| :--- | :--- |
| **Free & Open Source** | No licensing costs, community-driven |
| **Stability** | Servers running years without reboot |
| **Security** | Granular permissions, fewer malware targets |
| **Performance** | Lightweight, configurable, runs on anything |
| **DevOps standard** | 90%+ of cloud servers run Linux |
| **Career value** | Essential for DevOps, SRE, Backend Engineering |

### Linux in the Real World
- **Cloud:** AWS EC2, GCP, Azure all default to Linux instances
- **Containers:** Docker containers are Linux-based
- **CI/CD:** GitHub Actions, GitLab CI runners = Linux
- **Databases:** PostgreSQL, MySQL, Redis servers = Linux
- **Embedded systems:** Raspberry Pi, routers, Android

### Migration Mindset
- Linux is **not just an OS** — it's a philosophy: everything is a file, composable tools, scriptable by design
- You don't "install apps" the same way — you use a **package manager**
- The terminal is your **primary power tool**, not an afterthought
