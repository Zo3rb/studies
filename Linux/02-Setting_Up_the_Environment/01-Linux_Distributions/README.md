## 🎯 What This Lesson Covers

What Linux distributions (distros) are, the major distribution families, and how to choose the right one for your use case.

---

## 📝 Key Concepts

### What is a Linux Distribution?

A **Linux distribution** = Linux kernel + package manager + default software + configuration tools bundled together by a project or company.

### Major Distribution Families

| Family      | Base   | Package Manager       | Examples                    |
| :---------- | :----- | :-------------------- | :-------------------------- |
| **Debian**  | Debian | `apt` / `dpkg`        | Ubuntu, Linux Mint, Kali    |
| **Red Hat** | RHEL   | `yum` / `dnf` / `rpm` | CentOS, Fedora, Rocky Linux |
| **Arch**    | Arch   | `pacman`              | Arch Linux, Manjaro         |
| **SUSE**    | SUSE   | `zypper` / `rpm`      | openSUSE                    |

### Ubuntu vs CentOS — Course Perspective

|                   | Ubuntu                           | CentOS              |
| :---------------- | :------------------------------- | :------------------ |
| **Base**          | Debian                           | Red Hat             |
| **Package Mgr**   | `apt`                            | `yum` / `dnf`       |
| **Use Case**      | Desktops, cloud, dev             | Enterprise servers  |
| **Release Cycle** | Every 6 months (LTS every 2 yrs) | Stable, slow-moving |
| **Course focus**  | ✅ Primary                       | Secondary           |
