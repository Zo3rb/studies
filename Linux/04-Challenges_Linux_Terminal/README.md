# ⚡ Module 04 — Challenges: The Linux Terminal

## Overview

This module is the practical challenge section for **Module 03 — The Linux Terminal in Depth**. It is designed to test, reinforce, and solidify your hands-on mastery of essential Linux terminal operations. Rather than passive reading, these exercises demand active terminal interaction: interrogating documentation, categorizing shell commands, harnessing shell history for maximum speed, protecting sensitive inputs from history logs, auditing command execution timestamps, and securely managing administrative privileges with `su` and `sudo`.

## 🎯 Module Objective

Validate real-world terminal fluency by executing 10 essential command-line tasks without relying on GUI aids. By the end of this module, you will confidently:
- Look up command flags and documentation efficiently with `man` and `apropos`.
- Distinguish between shell builtins, keywords, aliases, and external binaries using `type`.
- Recall, search, and replay commands rapidly using history expansions (`!n`) and readline shortcuts (`Ctrl+R`).
- Execute commands securely without leaving plaintext traces in `.bash_history`.
- Configure `HISTTIMEFORMAT` for professional forensic auditing.
- Navigate privilege boundaries between unprivileged users, `su` login sessions, and audited `sudo` execution.
- Maintain and update user account credentials with `passwd`.
