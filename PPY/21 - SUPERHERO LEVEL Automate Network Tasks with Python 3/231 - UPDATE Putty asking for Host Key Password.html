When connecting via SSHv2 using Putty to each Arista VM, you will be asked to login.

The login credentials are the ones you configured earlier in the Necessary Switch/Router Configuration lecture, via the CLI in VirtualBox, using the username admin secret python command.

Therefore, use admin for the username and python for the password.
