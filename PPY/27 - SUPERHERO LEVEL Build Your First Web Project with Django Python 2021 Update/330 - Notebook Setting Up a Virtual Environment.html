In the Windows Command Line (cmd) type in the following commands:

E: (or navigate to your preferred partition)

cd django_blog

python -m venv venv

venv\Scripts\activate.bat


In the Windows Powershell (as Administrator) type in the following commands:

set-executionpolicy remotesigned

E:

cd .\django_blog\

python -m venv venv

venv\Scripts\Activate.ps1
