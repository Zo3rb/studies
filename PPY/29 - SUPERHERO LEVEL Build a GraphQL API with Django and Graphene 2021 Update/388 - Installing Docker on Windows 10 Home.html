Now, the main prerequisite is to have administrator rights on your Windows 10 Home machine, because we need to escalate privileges when installing the requirements. Next, to check the System Requirements:


  • Windows 10 version 1903 or higher, let’s check this by pressing the home key in Windows and search for Settings. Open the PC Settings app, go to System, go to the About section and here scroll down to Windows specifications.


  • Enable the WSL 2 feature on Windows.

    • Step 1 - Enable the Windows Subsystem for Linux: Open Powershell as Administrator and run the command: dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart


    • Step 2 - Update to WSL 2


    • Step 3 - Enable Virtual Machine feature: Run the following command in the admin Powershell prompt: dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

      Now, we need to reboot the machine.


    • Step 4 - Download the Linux kernel update package:

      • Download the latest package from the provided link: https://wslstorestorage.blob.core.windows.net/wslblob/wsl_update_x64.msi

      • Run the update package.


    • Step 5 - Set WSL 2 as your default version. Run the provided command in the same Powershell prompt: wsl --set-default-version 2


  • Now that we enabled the WSL 2 feature, go back to the docker requirements and the next one is to Download and install the Linux kernel update package, but we already did this in the WSL 2 sections, so we don’t have any other requirements to met.


Going further let’s get the docker installer from Docker Hub. Click the link and then click on Get Docker.


After the download finishes, run the executable file to start the installation. Make sure you check “Install required Windows components for WSL2” in the configuration page and click OK. Now wait for the installation to finish.


Docker Desktop installation succeeded. We have to log out to finish the installation, so click Close and log out. Then log back in.

Docker is going to automatically start, so wait for a bit before doing anything, and then continue with the instructions in the next video.
