It seems that the developers behind the openpyxl module decided to remove most of the color names (https://openpyxl.readthedocs.io/en/stable/_modules/openpyxl/styles/colors.html - check out the code under # Will remove these definitions in a future release) and replace them with the RGB hex values.

Therefore, you should replace this in your own code accordingly, using the codes in COLOR_INDEX in the aforementioned link.
