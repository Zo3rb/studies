Although in the video and in previous versions of openpyxl, the cell.column attribute returned the column letter (a string), in recent versions this has been changed and it now returns the column number.

So, for example, instead of column 'B' you will have 2 as a result.


Please find this change in the official documentation as well:

https://openpyxl.readthedocs.io/en/stable/api/openpyxl.cell.cell.html#module-openpyxl.cell.cell
