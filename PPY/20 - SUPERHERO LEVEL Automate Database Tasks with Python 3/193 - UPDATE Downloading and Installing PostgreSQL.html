1. Use the link below to download and install PostgreSQL on all platforms.

https://www.enterprisedb.com/downloads/postgres-postgresql-downloads


2. Click the Download button for version 10.x for your operating system and wait for the download to finish. For Windows users you most probably need the Windows x86-64 installer.


3. Double-click the installer and follow the installation steps by going with the defaults and setting the default password: python3 for this course.


4. After the installation is complete, open up PSQL - recently renamed to SQL Shell (psql). Go with the defaults for all the required parameters by hitting Enter at each prompt. Finally, for the password use python3, or the password you've set during installation.


5. Now everything is set up and works correctly. You can go ahead and follow the instructions in the rest of this section.
