# README.md for Loops and Iterations lesson

## 🎯 Learning Objectives
- Iterate over sequences with `for` and `while` loops.
- Use `enumerate`, `zip`, and `range` for advanced looping patterns.
- Apply loop control statements: `break`, `continue`, and `else`.
- Write list, set, and dict comprehensions.
- Annotate loop‑related functions with type hints.
- Follow PEP‑8 and Google‑style docstrings.
