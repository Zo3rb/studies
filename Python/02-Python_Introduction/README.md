# 🐍 Module 02 — Python Introduction

## Overview

Answers the foundational questions before the syntax begins: what a programming language is, what the Python interpreter actually does, how to run code, which version you are using, and why Python exists alongside so many other languages.

## 🎯 Module Objective

Describe the source → bytecode → VM execution pipeline in CPython, run Python in script, `-c`, REPL, and `-m` modes, inspect the active version with `sys.version_info`, explain the major Python 2 → Python 3 breaking changes, and articulate why language choice is a trade-off rather than a contest.
