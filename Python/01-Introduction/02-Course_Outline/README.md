## 📝 Key Concepts

### 1. The Section Map

The video course is organized into 24 top-level sections. The first six — the scope of this study folder — are:

| Section | Name | Role |
| :------ | :--- | :--- |
| 01 | Introduction | Orientation and outline |
| 02 | Python Introduction | What Python is, interpreter, running code |
| 03 | Python Basics | Data types, numbers, strings, lists, dicts, tuples, sets |
| 04 | Python Basics II | Conditionals, loops, functions, scope |
| 05 | Developer Environment | Installs, editors, CLI, PEP 8, Jupyter |
| 06 | Advanced Python — OOP | Classes, encapsulation, inheritance, dunders, MRO |

Later sections extend the same primitives into functional programming, decorators, error handling, generators, modules, debugging, file I/O, regex, testing, scripting, scraping, web development, automation testing, ML/data science, and career advice.

### 2. Two Kinds of Knowledge in the Course

1. **Language mechanics** — what `=` means, how `for` iterates, why `self` is explicit. These are covered once, carefully.
2. **Engineering habits** — clean code, PEP 8, debugging, testing, version control. These recur because they matter in every project.

```text
language mechanics → correct programs
engineering habits → maintainable programs
```

### 3. What "Zero to Mastery" Means Here

"Mastery" is not memorizing every built-in. It is being able to:

- read unfamiliar Python and explain it,
- choose the right data structure for a problem,
- debug by forming and testing hypotheses,
- and ship a small project without hand-holding.

## ⚠️ Gotchas & Pro Tips

1. **The outline is a promise, not a schedule.** Move faster through topics you already know; slow down when `practice.py` surprises you.
2. **Exercise videos are first-class lessons.** In this repository they get their own folder and practice script — they are where understanding becomes skill.
3. **Developer Fundamentals segments are checkpoints.** Treat them as mini-quizzes embedded in the course, not skippable interludes.
