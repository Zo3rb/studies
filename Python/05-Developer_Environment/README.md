# 🐍 Module 05 — Developer Environment

## Overview

Set up a reliable Python workspace from the ground up. This module walks through installing Python on macOS and Windows, verifying the interpreter and PATH, comparing lightweight editors with full IDEs, and getting comfortable running code from the terminal. It finishes with PEP 8 formatting conventions and Jupyter notebooks, so the environment you build is both reproducible and pleasant to work in.

## 🎯 Module Objective

Build a developer environment you can explain and reproduce: install and verify Python on any major operating system, choose an editor with a deliberately selected interpreter, navigate and run code from the terminal, keep code consistently formatted, and know when a notebook is the right tool. By the end you should be able to diagnose the common PATH, interpreter, and missing-package problems without guesswork.
