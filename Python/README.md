# 🐍 Complete Python Developer — Zero to Mastery

Welcome to the **Python** study repository! This project follows the *Complete Python Developer: Zero to Mastery* video course, building a deep language foundation before moving into real-world Python work.

## 🎯 Goal

Master Python from first principles through **Module 06 — Advanced Python: Object-Oriented Programming** — documented, practiced, and self-assessed — as the foundation for the remaining course modules (functional programming, decorators, generators, modules, testing, web, scraping, automation, and data science).

## 🛠️ Project Structure

Each module folder contains:

- `README.md` — Module overview, lesson index, and learning objectives
- `<lesson-name>/README.md` — Distilled notes, accurate Python snippets, and gotchas from that exact video
- `<lesson-name>/practice.py` — Runnable, deterministic, standard-library-only practice script
- `quiz.md` — Module-level self-assessment questions and answer log (the course has no separate quiz videos)

Study loop:

```text
watch video → read lesson README → run practice.py → answer quiz.md → revisit gaps
```
