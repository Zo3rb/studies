**Goal**: Go from complete beginner to job-ready backend developer by writing a lot of code, building real projects, and mastering both computer science fundamentals and practical backend systems.

**Estimated time**: ~12 months for most beginners (depends on weekly hours and prior experience).  
**Primary languages**: Python → TypeScript  
**Key technologies**: SQL, Docker, HTTP, Linux, Git, Pub/Sub, Object Storage / CDNs

This repository is structured as a progressive learning journal. Each module has its own folder where you can store notes, exercises, solutions, screenshots, and personal reflections.

---

## How to Use This Repo

1. Work through the modules **in order**.
2. Create notes, code, and reflections inside each module’s folder.
3. Mark progress by updating the status checkboxes below or adding a `STATUS.md` inside the folder.
4. Treat the **Personal Project** and **Capstone** seriously — they become the strongest pieces of your portfolio.
5. Feel free to add your own resources, diagrams, or links inside each folder.

## Tips for Success

- Write code every day, even if only for 30–60 minutes.
- Use the guided projects as training; treat the personal and capstone projects as real portfolio work.
- Document your learning inside each folder (what was hard, what clicked, useful resources).
- Keep a public GitHub profile updated as you complete modules.
- The goal is not just finishing the path — it is becoming someone who can independently design and build backend systems.
