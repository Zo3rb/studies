## 🛠️ Project Structure

This repository uses the same proven structure as our Advanced PostgreSQL project. Each lesson contains:

- `README.md`: Detailed theory and concepts.
- `practice_trainings.sql`: Sandbox scripts for isolated DDL/DML practice.
- `practice_dvdrental.sql`: Real‑world querying practice using the `dvdrental` sample database.
