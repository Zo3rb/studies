## 🎯 Learning Objectives

By the end of this module, you will understand:

- How to write standard `INNER JOIN` queries to find matching records.
- The differences between `LEFT JOIN` and `RIGHT JOIN` for retaining unmatched records.
- How to detect anomalies like orphaned data using `LEFT JOIN ... WHERE ... IS NULL`.
- How to combine distinct datasets using `UNION` and `UNION ALL`.
