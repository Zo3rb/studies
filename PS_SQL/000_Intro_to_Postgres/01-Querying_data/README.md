## 🎯 Learning Objectives

By the end of this module, you will understand:

- How to use `SELECT`, `FROM`, `WHERE`, `GROUP BY`, and `HAVING`.
- Pattern matching with `LIKE` and `ILIKE`.
- Proper handling of `NULL` values.
