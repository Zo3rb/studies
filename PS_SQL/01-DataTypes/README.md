# 📊 Module 1: PostgreSQL Data Types

Welcome to the first module of our database learning journey. PostgreSQL has a rich set of native data types. Choosing the correct data type is critical for storage efficiency, query performance, and maintaining data integrity—fundamental skills for database engineering and data representation in AI/ML systems.

This module is aligned with the video course **"Mastering Postgres - A video course on PostgreSQL"**.

---

## 🎯 Module Objective

To master the usage, limits, storage characteristics, and operations of key PostgreSQL data types, and to build hands-on experience through exercises on the empty `trainings` database and the analytical `dvdrental` database.

## 🛠️ Practice Environments

1. **`trainings` Database (DDL & DML):**
   - Used to practice schema design, creating tables, defining constraints, inserting data, testing boundary limits, and observing data-type errors.
2. **`dvdrental` Database (Querying):**
   - Used for analytical querying, type casting, searching, sorting, and observing how different data types are structured in existing database schemas.
