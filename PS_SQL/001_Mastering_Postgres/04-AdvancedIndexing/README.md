# 🚀 Module 4: Advanced Indexing

Welcome to **Module 4**! Building on our foundation from Module 3, we now explore advanced indexing techniques and alternative index types in PostgreSQL.

## 📖 Module Overview

| Lesson | Topic | Description | Status |
| :--- | :--- | :--- | :---: |
| **01** | [Functional Indexes](./01-Functional_Indexes/) | Indexing the result of an expression/function | 📅 |
| **02** | [Duplicate Indexes](./02-Duplicate_Indexes/) | Identifying and removing redundant indexes | 📅 |
| **03** | [Hash Indexes](./03-Hash_Indexes/) | Equality-only indexes in PostgreSQL | 📅 |
| **04** | [Naming Indexes](./04-Naming_Indexes/) | Best practices and naming conventions | 📅 |

---

## 🎯 Learning Objectives

By the end of this module, you will understand:
- How to speed up queries that rely on string manipulation or math functions (`LOWER()`, etc.) using **Functional Indexes**.
- Why maintaining duplicate indexes harms performance and how to find them.
- When to use **Hash Indexes** instead of B-Trees.
- Consistent naming conventions for your database schema.
