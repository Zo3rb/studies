# 📊 Cost & Rows

In this lesson we dive into the cost estimation and row count predictions that PostgreSQL provides in an `EXPLAIN` plan. You’ll learn how to read the `cost=..` and `rows=` fields, what they mean, and how to use them to spot inefficient plans.

## Topics Covered
- Understanding startup and total cost values
- How PostgreSQL estimates row counts
- Impact of statistics on cost estimation
- Adjusting planner settings to improve estimates
