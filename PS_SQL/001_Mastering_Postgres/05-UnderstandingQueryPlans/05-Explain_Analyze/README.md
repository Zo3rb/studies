# 📈 EXPLAIN ANALYZE

This lesson shows how to use `EXPLAIN ANALYZE` to obtain actual execution times, row counts, and I/O statistics for a query. You’ll learn how to interpret the additional information provided compared to a plain `EXPLAIN`.

## Topics Covered

- Running `EXPLAIN (ANALYZE, BUFFERS, VERBOSE)`
- Understanding actual vs. estimated rows and costs
- Interpreting timing and buffer usage
- Using the output to pinpoint performance bottlenecks
