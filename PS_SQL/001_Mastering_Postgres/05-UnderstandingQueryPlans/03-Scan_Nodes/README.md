# 🔍 Scan Nodes

This lesson covers the different scan node types PostgreSQL can use when executing a query, including Sequential Scan, Index Scan, Bitmap Index Scan, and Bitmap Heap Scan.

## Topics Covered
- When PostgreSQL chooses each scan type
- Performance implications of each scan
- How to read scan node information in the `EXPLAIN` output
