# Database Documentation

This folder contains everything related to the PostgreSQL `trainings` database.

Phase 2 establishes the v1.1 multi-tenant SaaS baseline. The files below document the schema, data types, migration strategy, and required extensions.

- `schema.md` – Logical schema & ERD
- `data-types.md` – All PostgreSQL data types with project-specific examples
- `migrations.md` – Migration strategy
- `extensions.md` – Recommended PostgreSQL extensions
