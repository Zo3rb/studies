# API Design

RESTful endpoints are defined for Phase 2 and should follow the conventions in [phase-2-plan.md](phase-2-plan.md).

## Base Path

Example base path: `/api/v1/`

## Initial Endpoint Groups

- Authentication and current user
- Users and profile data
- Courses and course content
- Enrollments and progress
- Uploaded files and avatar references
- Categories and tags
- Operational endpoints for health and readiness

## Future Documentation Layer

Swagger/OpenAPI will be added later in Phase 2 so the endpoint map can be tested interactively and kept in sync with the backend implementation.
