# trainings-platform

A practical, full-stack knowledge-testing & learning platform built from scratch to master:

- PostgreSQL (core focus)
- Full-stack development (Node.js + Prisma + native SQL + React)
- Python-based analytics & AI/ML pipelines

**Goal**: Learn by building a real system end-to-end — from raw SQL to production reports and ML features.

## Quick Start (Documentation-First Approach)

1. Read `docs/README.md` (Documentation Index)
2. Read `docs/architecture.md`
3. Explore `docs/database/` (especially `data-types.md` and `schema.md`)
4. Follow the phased roadmap in `docs/roadmap.md`

## Tech Stack

- **Backend**: Node.js + Prisma ORM + native PostgreSQL queries
- **Frontend**: React + REST API
- **Database**: PostgreSQL (`trainings`)
- **Analytics/ML**: Python (pandas, scikit-learn, etc.)
- **License**: MIT (Open Source)

This repository is living documentation. Everything is tracked on GitHub from day one.

Built as a hands-on guide by a 20-year veteran Software Engineer & Data Scientist.
